## 📚 项目简介

**GudaStudio Commands** 是 **GudaStudio** 开发的自定义命令集合，专为 Claude Code 设计。核心命令 `gudaspec` 提供基于**RPI(Research-Plan-Implementation)编码理论**的完整流程。这些命令使得 Claude Code 在复杂场景与长时间编程任务中更加高效。同时，本项目采用以人为本的设计，允许用户通过手动分割上下文，让 Claude Code 的有效上下文（约80K）得到最佳利用。

### ⚙️ gudaspec 命令集

| 命令              | 功能                                         |
|-------------------|--------------------------------------------|
| `/gudaspec:init`  | 初始化 OpenSpec 环境，验证 MCP 工具的可用性 |
| `/gudaspec:researc` | 进行有效的研究规划                       |

## 👍 Using GudaStudio Commands

### Initial Setup

The first time you run the application, you’ll need to set it up. For initial setup:

1. Click on the `/gudaspec:init` command.
2. Follow the on-screen prompts to set up the OpenSpec environment.
3. Verify that the MCP tools are available.

### Applying Commands

To utilize the commands:

1. Open the application.
2. Type your command in the input area.
3. Press Enter to execute the command.
